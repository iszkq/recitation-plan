# iPhone 覆盖升级验收

状态：待真实 iPhone 执行。Windows 上的持久化与模拟容器路径迁移测试通过，不能视作真机通过。

## 准备与覆盖安装

1. 在旧版本0.2.2或实际使用版本中记录文章/段落数、计划及原截止日期、已完成任务和成绩、延期任务前后日期、报告掌握数。导出一份档案，保存到“文件”并确认可找到。
2. 新IPA需使用此前同一签名身份及应用标识 cn.recitation.recitationApp 签名。保留旧应用，直接覆盖安装0.2.3+5；不要先卸载。未签名IPA不能直接安装。
3. 打开新版，核对上述内容和日期均保留。旧版延期仍显示，但缺失来源日期的旧记录不能撤销。关闭并重开，再核对档案。
4. 延期一项到自选日期，检查原有+移入工作量正确，其他任务与已完成成绩不变。撤销后回原日期；反复点击不会重复撤销。再次延期后，旧记录不再允许撤销。
5. 完成今日任务后提前通过明天的新背，检查完成提示与下次复习；到原定日期不需重做。辅助练习与待复核不能产生完成。

## 通知与导出

1. 首次进入提醒设置不弹权限。开启学习提醒时允许通知，选择未来几分钟的北京时间；切到后台或锁屏，检查通知标题和点击打开。前台通知展示由系统处理，不以横幅出现作为唯一验收方式。
2. 同一天任务全部完成且没有到期剩余任务后，原当日学习提醒不应触发；延期、撤销、暂停后检查通知反映活跃待完成任务。提醒文案不虚报固定任务数。
3. 拒绝权限后开关不自动开启，说明可到系统设置开启。系统允许后回应用刷新，重试开启；在系统撤回权限后回应用，显示未允许。
4. 每周备份默认关闭。开启后系统安排七日提醒；取消分享不产生导出时间，成功分享并实际保存后显示上次导出日期。通知只提醒保存，不宣称自动云备份。
5. 新版导出JSON后，在独立测试档案恢复，核对延期/撤销历史、成绩和报告。不要用恢复操作覆盖唯一未备份的真实学习档案。
