# 正式产品实施计划

## 当前已落地

- 独立的纯 Dart 核心层，不修改 `vendor/remember-me` 上游快照。
- 文章、原文版本、段落、计划、任务、考核记录和规则快照模型。
- 中文规范化、动态规划对齐、内容一致率和原文覆盖率计算。
- 按本地日期、学习日和每日配额生成新背任务。
- 核心规则测试样例，覆盖标点、漏字、多说和截止日边界。
- 学习事件聚合为周报、月报和年报，分母只使用真实到期任务/复习考核。
- 版本化本机档案格式，恢复前可校验清单且默认不包含录音。
- 导入预览、空行分段、按句拆分/合并函数。
- 自动通过后按 1/3/7/14/30 天生成稳定 ID 的间隔复习任务。
- 本地仓库接口与内存实现：处理中考核可更新为最终结果，最终记录不可被重复回调覆盖。

- 2026-10-08新增Hive、业务服务与备份服务；Dart分析无错误，33项测试通过，已跑通文字考核的本机持久化闭环。
- 2026-10-08新增 Flutter App：本机存储启动、导入/分段、计划预览及门槛设置、今日任务、全文阅读、无提示文字考核、计划详情、周/月/年报告、系统分享备份及档案恢复。已生成 iOS/Android 工程并配置 GitHub 未签名 iOS 构建。

## P0：首个可用版本

1. Dart/Flutter 工具链已在 Windows 安装。GitHub 工作流需首次运行验证 iOS 构建。
2. 中文 Cupertino 导航与页面已建立；独立核心层没有复制上游实现，录音组件待接入。
3. 已用Hive保存本机快照，带schema版本；已连接Flutter页面，后续版本迁移待实现。
   核心层通过 `RecitationStore` 接口依赖存储，Hive 只是正式 App 的一个适配器。
4. 文字导入、分段编辑、计划预览、今日任务和文字考核已接入。
5. 核心评分已接到结果页，只有最终结果且满足规则才完成任务。
6. 通过后创建间隔复习任务；重复最终回调不能重复生成任务。
7. 本机备份导出/恢复和错误提示已接入；系统选择/分享、异常存储与崩溃恢复仍需真机验证。

## P1：真实语音与上线质量

1. `record` 只负责录音；通过 Provider 接入 Apple Speech 最终转录。
   核心层通过 `SpeechProvider` 接收临时/最终状态，临时文字永远不能写入通过记录。
2. 处理权限、无声、识别失败、来电、后台、取消和最终化超时。
3. 保留转录、置信度、时间片段、录音路径和规则快照；疑点必须可回听。
4. 用真实中文录音集校准同音字、停顿、口音、数字、专名和漏整句。
5. 完成动态字体、VoiceOver、深色模式、横竖屏和低存储空间测试。

## P2：账户、统计与同步

1. 先实现无账户本机档案和完整导出，再接 Apple 登录。
2. 同步使用事件 UUID 和幂等键；合并前展示冲突，不覆盖原文版本。
3. 从事件生成周报、月报和年报；分开统计自动通过、人工确认和辅助练习。
4. 录音默认不上传，云端录音单独开关并提供删除操作。

## 不应提前承诺

- Apple Speech 等同于专业普通话发音评分；
- 所有设备都支持完全离线中文识别；
- 云端同步已经可用；
- 仅凭报告分数就能准确推断长期记忆能力。
