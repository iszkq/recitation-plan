# 组件契约

| 组件 | 结构 | 状态 | 交互/无障碍 |
|---|---|---|---|
| 大标题页头 | 标题、副说明、右侧操作 | 正常、空数据 | 标题真实 h1；新增图标中文标签 |
| 内容页顶栏 | 返回、页面名、可选保存 | 保存中、已保存、草稿 | 返回目标44pt，未保存返回提示 |
| 主按钮 | 图标可选＋短文案 | 默认、按下、禁用、处理 | 52px；处理时防重复提交 |
| 文本列表项 | 图标、标题、元信息、进度 | 待背、待复习、已完成 | 整行可触控，长标题换行 |
| 段落列表 | 段序、节名、正文摘要 | 拆分、合并、编辑 | 实际 App 支持拖拽和无障碍移动按钮 |
| 表单行 | 标签、值、补充说明 | 错误、禁用 | 阈值和日期有可见标签 |
| 底部导航 | 今日、文库、计划、我的 | 当前项 | 图标＋中文名；考核时隐藏 |
| 阅读正文 | 原文、首字、遮字 | 阅读、练习、有辅助 | 字号可调；考核不显示原文 |
| 录音状态 | 时间、麦克风状态、进度 | 录音、暂停、最终化、中断 | 波形非唯一状态提示 |
| 分数摘要 | 分数、通过状态、条件 | 通过、不通过、待复核 | 一位小数；判定使用未四舍五入值 |
| 指标单元 | 数值、名称、补充说明 | 正常、完成、无数据 | 数值和名称同时朗读，不依赖颜色表达状态 |
| 图标徽章 | 线性图标、浅色背景 | 默认、成功、错误 | 图标仅作辅助，旁边必须保留文字说明 |
| 校对片段 | 原文与转录、错误标记 | 漏背、错词、识别疑点 | 用文字、下划线与颜色共同传达 |
| 复核条目 | 音频片段、识别结果、反馈 | 待确认、人工确认、重试 | 人工确认保留审计，不能变成自动通过 |
| 空/加载/错误 | 简明说明、主要行动 | 空文库、解析中、识别失败 | 不用占位数据伪装真实信息 |

所有重复组件共享 CSS 语义类及 tokens。静态展示板中的日期、文章与评分为设计样例；可点击原型在外壳明确告知演示性质。

账户沿用顶栏、列表、表单开关与主要按钮。报告复用分段切换、进度、统计和文章列表，新增月度柱形图：每月显示数值与月份，并提供完整无障碍文本；不以颜色单独表达数据。

## Flutter 映射

`product/app/lib/design.dart` 集中维护颜色、系统字体、字号和间距，使用 `PrimaryAction`、`DetailRow`、`EmptyContent` 复用操作、列表和空态。页面使用 Cupertino 导航、日期选择器、分段控件和滑杆；内页通过根导航覆盖底部导航。配额控件采用纵向排列以容纳窄屏大字体。

阅读页保留完整正文，列表只显示摘要；考核页独立隐藏原文，提交后才显示校对。iOS 系统语音识别已接入，临时转录在考核中隐藏，只有最终结果能进入校对。录音不保存；首字辅助、回放、拖拽排序与手动字号控制仍是后续目标。报告已显示真实完成事件趋势。

计划创建页支持多篇文章，文章选择使用系统复选框；按选择顺序生成任务。计划详情使用开关暂停/继续，保留任务与历史，暂停不改写排期或已有报告。前台恢复和本地午夜自动刷新今日任务。

## 本次实现契约

今日页复用系统确认弹窗提供“将剩余任务延至明天”，处理时禁用重复操作。提前学习页复用系统分段控件切换明天/后天，任务列表沿用 DetailRow；只有今日队列清空后的未完成新背任务可进入提前考核。任务日期说明分别显示原定日期、延期或实际提前完成日期，已完成和复习待到期条目不提供提前入口。延期后明天原有任务保持原日期，延期任务并入明天；截止日期不自动移动，原定目标仍可追溯。

主背景为白色，卡片白底、浅灰细边框、16pt 圆角；浅灰只用于控件及分组。CardSection、DetailRow、ProgressBar、StatusChip 统一页面层级。列表在有页边距的容器内使用 inset: false，避免叠加 48pt 边距。阅读和编辑不将每句原文卡片化。

报告趋势按实际完成日期统计：周按天、月按七天分组、年按月份；54pt 列宽、22pt 柱宽、96pt 图高，可水平滚动，附明确提示和逐列无障碍数值。0 不虚构柱高，未发生的数据保持零。图中任务数量与到期任务完成率使用不同统计口径并分别标注。

语音考核使用计时和状态文字表示录音，不使用伪造百分比进度；最终化显示加载态并禁止重复提交。录音退出需确认，权限失败可重试，中断与自动通过分别记账。

文库复用系统搜索框、分段筛选和带进度的文章列表项；作者、节数和掌握数均来自本机档案。编辑后的新版本进度独立计算，搜索无结果和筛选空结果有明确提示。

## 0.2.3 扩展

Flutter 的 PickerSheet 共用于日期与提醒时间，330pt 高度集中定义于 Design；PostponePage 复用 DetailRow、CardSection、PrimaryAction，显示工作量后确认。PostponementHistoryPage 显示前后日期和撤销状态，仅最近一次未完成任务可撤销。CompletionFeedback 仅在已保存的无辅助自动通过后显示完成和下次复习。ReminderSettingsPage 复用 CupertinoSwitch，每个开关有中文语义标签；默认关闭，申请失败不启用。页面和弹窗支持 320pt/1.5 倍字号回归。

延期历史的 DetailRow 使用可变高度完整副说明，关键日期与撤销状态不受默认三行摘要限制；窄屏大字体按内容换行。

## 0.2.5 校对与成长

TextComparison共用于文字和语音结果，SelectableText富文本保留标点、换行和复制；语音同音容错可在录音前切换，结果按该次记录的模式展示，原始文本默认收起。差异列表与高亮来自同一次对齐。GrowthPage使用真实学习事件、120pt小芽图形、周目标1至7天控件及已获得/待解锁徽章列表，动态大字体纵向滚动。开源许可由系统许可页显示。
