# 数据与同步方案

正式产品先保证本机可用，再接账户和云同步。核心层通过 `RecitationStore` 和 `SpeechProvider` 接口与具体技术隔离，当前实现位于 `product/core`。

## 本机实体

| 实体 | 稳定主键 | 保存内容 |
|---|---|---|
| Article | articleId | 标题、作者、当前版本 |
| ArticleVersion | articleVersionId | 原文版本、创建时间、变更说明 |
| Segment | segmentId | 段落顺序、正文、关键项 |
| Plan | planId | 文章段落快照、配额、日期、规则、时区 |
| Task | taskId | 新背/复习、到期日、完成状态 |
| Attempt | attemptId | 最终转录、来源、状态、分数、规则快照 |
| LearningEvent | eventId | 练习、考核、任务和报告统计事件 |

## 当前 Hive 实现

正式本机实现为 `product/core/lib/src/hive_store.dart`。用独立盒子`recitation_snapshot_<路径摘要>`，单键`state`存版本化JSON，schemaVersion=1；使用Hive公开API，不注册新适配器、不复用上游typeId、不关闭上游其他盒子。

先序列化整个批次、持久化并flush，再发布内存状态。未知schema拒绝启动，保留文件，不自动清库。大型档案整份快照写入会增加成本，后续必须按性能实测升级；尚未验证强制断电和多进程写入。typeId20–26方案是未来拆盒子的候选方案，当前未使用。

## 业务写入

1. 确认导入后，文章与不可变原文版本一起写入；历史版本不能被覆盖。
2. 计划、全部新背任务与到期事件一起写入；容量不够不写入。
3. 临时转录拒绝考核；只有最终结果可以提交。已有processing会话可更新成最终结果。
4. 最终成绩、自动完成任务、首次新背通过后的复习任务与统计事件一起写入。
5. 同一最终会话ID重复/并发提交不重复完成任务。任务已完成不能被重放旧排期重置成待背。
6. 复习通过不会反复创建首次掌握的1/3/7/14/30天任务；自适应间隔和漏背重排后续扩展。

## 导出与恢复

`ArchiveBundle` 使用 `formatVersion`、`profileId`、`exportedAt`、`timeZone` 和实体数量清单。恢复前先校验格式、实体列表和校验和，再预览新增、重复和冲突项。当前恢复拒绝冲突并返回列表；后续提供明确选择后新建ArticleVersion的解决流程，不能静默覆盖；CSV 只作为阅读报表，不能当作完整恢复档案。

## 账户同步

未登录档案拥有 `localProfileId`。登录后先展示本机与云端记录数量，用户明确选择合并或切换；使用事件 UUID 去重，按 UTC 时间和档案时区计算报告。退出账户不删除本机数据，录音默认不上传，云端录音需要单独开关。
