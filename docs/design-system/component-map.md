# 组件契约

| 组件 | 结构 | 状态 | 交互/无障碍 |
|---|---|---|---|
| 大标题页头 | 标题、副说明、右侧操作 | 正常、空数据 | 标题真实 h1；新增图标中文标签 |
| 内容页顶栏 | 返回、页面名、可选保存 | 保存中、已保存、草稿 | 返回目标44pt，未保存返回提示 |
| 主按钮 | 图标可选＋短文案 | 默认、按下、禁用、处理 | 52px；处理时防重复提交 |
| 文本列表项 | 图标、标题、元信息、进度 | 待背、待复习、已完成 | 整行可触控，长标题换行 |
| 段落列表 | 段序、节名、正文摘要 | 拆分、合并、编辑 | 实际 App 支持拖拽和无障碍移动按钮 |
| 表单行 | 标签、值、补充说明 | 错误、禁用 | 阈值和日期有可见标签 |
| 底部导航 | 今日、文库、计划、我的 | 当前项 | 图标＋中文名；考核时隐藏 |
| 阅读正文 | 原文、首字、遮字 | 阅读、练习、有辅助 | 字号可调；考核不显示原文 |
| 录音状态 | 时间、麦克风状态、进度 | 录音、暂停、最终化、中断 | 波形非唯一状态提示 |
| 分数摘要 | 分数、通过状态、条件 | 通过、不通过、待复核 | 一位小数；判定使用未四舍五入值 |
| 校对片段 | 原文与转录、错误标记 | 漏背、错词、识别疑点 | 用文字、下划线与颜色共同传达 |
| 复核条目 | 音频片段、识别结果、反馈 | 待确认、人工确认、重试 | 人工确认保留审计，不能变成自动通过 |
| 空/加载/错误 | 简明说明、主要行动 | 空文库、解析中、识别失败 | 不用占位数据伪装真实信息 |

所有重复组件共享 CSS 语义类及 tokens。静态展示板中的日期、文章与评分为设计样例；可点击原型在外壳明确告知演示性质。

账户沿用顶栏、列表、表单开关与主要按钮。报告复用分段切换、进度、统计和文章列表，新增月度柱形图：每月显示数值与月份，并提供完整无障碍文本；不以颜色单独表达数据。

## Flutter 映射

`product/app/lib/design.dart` 集中维护颜色、系统字体、字号和间距，使用 `PrimaryAction`、`DetailRow`、`EmptyContent` 复用操作、列表和空态。页面使用 Cupertino 导航、日期选择器、分段控件和滑杆；内页通过根导航覆盖底部导航。配额控件采用纵向排列以容纳窄屏大字体。

阅读页保留完整正文，列表只显示摘要；考核页独立隐藏原文，提交后才显示校对。当前实现不含录音、首字辅助、拖拽排序、手动字号控制及报告图表，这些是后续设计目标。

计划创建页支持多篇文章，文章选择使用系统复选框；按选择顺序生成任务。计划详情使用开关暂停/继续，保留任务与历史，暂停不改写排期或已有报告。前台恢复和本地午夜自动刷新今日任务。
