# 提前学习与延期

本次实现位于正式 Flutter App 和 Dart 核心层，HTML 设计原型没有同步扩展。

本次发布版本为 0.2.2+4，应用标识保持原值。覆盖升级兼容修复优先读取目录内已有的 Hive 档案文件，即使 iOS 数据容器绝对路径变化也沿用原文件名。旧格式验证失败或发现多个候选档案时停止加载并保留原文件，不自动创建空档案。仍需同一应用标识与签名身份进行覆盖安装，卸载会删除系统管理的本机数据。

## 行为

- 今日队列清空后，从今日页“提前学习”切换明天/后天的新背任务，或从计划详情进入。文字、语音考核使用原评分门槛，只有无辅助的最终自动通过完成任务。
- 提前完成保留原排期与实际完成事件，未来当天不再要求重做。新背复习以实际通过日生成，复习不能提前考核。
- 今日页“将剩余任务延至明天”确认后，将队列内所有未完成新背和复习并入明天，包括逾期任务。明天原有任务保留，已完成任务不变；即使明天不是常规学习日也执行用户选择。
- 重复延期保留最初排期。延期不生成通过成绩，不自动改动原目标截止日。
- 延期写入任务和调整事件的同一事务。并发重复提交或旧考核事务不能覆盖调整后的日期，保存失败不会发布部分内存状态。
- 报告到期完成率按调整日期核算，提前通过跨月仍能计入到期月份的已完成任务；掌握、时长和学习天数按实际发生日期核算。没有实际完成活动的未来日期不会产生学习打卡。
- 老档案缺失原日期/调整事件字段时继续使用旧排期；新字段随 Hive 和结构化备份保存。
