# 延期撤销与本地提醒

版本 0.2.3+5，应用标识 cn.recitation.recitationApp，最低 iOS 15。

## 实现

- 今日剩余任务保留快捷延至明天，确认显示明天原有、移入和总工作量。也可自选更晚日期。
- 背诵准备页和计划详情可单项延期，支持未来未完成任务；新背与复习都可延期。延期不改原截止日、不生成通过记录。
- 延期记录可撤销最近一次未完成任务的延期，恢复到上一日期。恢复到今天或过去时返回今日队列。已完成、暂停、删除、旧版缺失来源日期、再次调整的旧记录不能撤销。
- 撤销保留独立事件与原延期关联；原定日期、任务和事件一起保存。并发撤销及过期事务被拦截，不部分保存、不复活旧延期。
- 文字与语音自动通过反馈显示提前完成的原定日期，新背显示实际首过生成的下次复习。有辅助或待人工复核不会显示完成。
- “我的→提醒设置”提供学习提醒、每周备份提醒、时间设置；默认关闭，只在用户开启时申请通知权限。使用北京时间。
- iOS 系统通知原生实现，无新增通知库。安排未来三十个日历日（已过今日时间则不安排今日），只针对活跃计划的待完成任务；最多30条学习通知和1条备份通知。打开、前台恢复、跨日、完成、延期、撤销、暂停等会刷新。应用长期不打开时三十天后学习提醒停止续排。
- 每周备份提醒按首次使用或上次成功分享导出的北京时间日期加七个日历日，在所选时间提醒；已逾期安排下一个所选时间。没有学习内容不提醒。取消或不可用的分享不更新导出时间；导出完成后请实际保存到“文件”或云盘。本功能只提醒，不上传或自动备份。
- 设置写入独立 reminders.json，不修改学习快照。损坏/失败有提示；通知调度失败不回滚已保存学习数据，可刷新重试。备份 JSON 包含延期与撤销历史，通知权限和设备偏好不跨设备导入。

## 自动检查

核心测试覆盖单项/批量、未来任务、日期跨月、重复撤销、同时间再次延期、并发撤销、旧版事件、暂停/完成限制、报告口径、JSON备份和Hive重开。

Flutter 测试覆盖延期工作量确认、日期选择、退出旧准备页、撤销返回今日、提前通过反馈、无辅助限制；提醒覆盖默认关闭、用户拒绝、权限撤回、调度失败、设置读写失败、UTC通道、完成/暂停/延期更新和七日重新计时。五个排期/设置页面覆盖390pt及320pt/1.5倍字体。

Windows 无 Xcode；此处自动检查与截图不替代 iPhone 通知、权限、分享和覆盖升级实测。CI 和 IPA 结果在完成后补录。
