# 本次发布验收

版本：0.2.0+2。目标仓库：https://github.com/iszkq/recitation-plan 。

## 已实现并验证的范围

- 文库：按文章标题和作者搜索；全部、背诵中、已完成筛选读取真实计划与当前原文段落进度，编辑后的新原文不继承旧成绩。
- 中文 iOS 风格：今日、文库、计划、文章详情、编辑、导入、分段、阅读、考核、我的、备份和报告复用共享组件；窄屏不叠加页边距，学习日选中有系统按钮状态。
- iOS 中文语音考核：权限、开始/停止、只提交最终转录、自动结束、15 秒最终化超时、中断清理、退出确认；实时转录隐藏。无录音持久化或原文补全。
- 编辑文章生成新版本；详情即时刷新，已有计划继续使用原版本。删除先检查所有被计划引用的版本。
- 计划名称和考核门槛可编辑，暂停/继续及删除可操作；删除取消未完成任务并保留历史。
- 删除采用隐藏标记，历史关联完整。包含通过和失败成绩的删除档案可导出，并恢复到新设备。
- 周/月/年报告显示真实事件统计及任务完成趋势；零数据保持零，图表逐列提供无障碍文字。
- 备份导出、校验和、冲突拒绝、恢复前保存旧档案沿用原实现。

## 明确限制

- Windows 不具备 Xcode；真实麦克风、Apple Speech、来电/后台中断、联网识别、权限恢复、文件选择、系统分享和语音中文错误率仍需 iPhone 验收。受控适配器测试不替代这些平台测试。
- 当前是本机保存版本，没有 Apple 登录和云同步；更换设备或卸载前导出档案。
- “一致率”是最终转录与原文的文本评分，没有专业音素/发音评分或同音字自动校正。系统识别误差仍可能影响成绩。
- 不保存录音，不支持回放或识别疑点的音频复核；人工修订不能生成自动通过。
- 计划设置编辑支持名称与考核门槛；文章、日期、学习日和每天配额的重新排期需另建计划。
- 首字辅助、拖拽排序、手动字号控制和定时通知尚未实现。导入当前支持粘贴及 TXT 文件。
- 未签名 IPA 是构建产物，重新签名后才能安装，不能直接用于 TestFlight。

## 界面验收结论

检查了层级、间距、共享组件、真实状态、中文文案、触控范围和窄屏大字体布局。修正了重叠边距、录音伪进度、实时转录提示和原文版本刷新。当前可以交付未签名内测构建；真机语音验收与正式签名仍是上线前必要工作。
