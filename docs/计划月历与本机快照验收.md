# 计划月历与本机快照验收（0.2.4+6）

## 功能与入口

- 今日 → 计划月历；计划详情 → 查看本计划月历。按真实到期日显示任务，区分新背、复习及完成。暂停计划仍显示，不能开始考核。
- 计划详情 → 重新安排剩余新背。按原文顺序，选择开始日、每日配额及学习日，预览工作量后确认保存。已完成任务和复习保留，原截止日不变；无法在截止日前完成时禁止保存。
- 今日存在积压复习时 → 整理积压复习。仅处理活跃计划中今天之前的待完成复习，已有复习占每日配额。同段复习分天保留，不合并、不跳过、不增加通过或完成记录。已有未来复习保留原日期，所以整理后的复习不一定按原间隔序号执行；复习本来就可能超过计划截止日。
- 我的 → 备份与恢复 → 本机快照。学习档案每次变化前留存最近快照；北京时间每日首次变化前留存每日快照。最多保留有效的最近12份、每日14份、手动5份及恢复前5份；不是每日后台定时任务。

## 数据保护

批量排期保留原定日期、真实成绩、考核、原文与历史；新增调整事件与单项延期区分，不能逐项撤销批量排期。预览期间完成任务、改计划、新建/恢复活跃计划、改日期、跨日或并发提交使旧预览失效，整批拒绝。

恢复是明确回滚，而外部档案恢复仍是冲突安全合并。先校验格式、实体、关联与校验和，展示恢复范围，保存当前完整结构化档案成功才替换。恢复期间当前档案变化会拒绝覆盖。恢复后可从“恢复前档案”切回；磁盘保存失败不发布替换状态。

快照失败不阻断正常学习保存，页面提示检查空间/导出。坏快照原文件保留、禁用恢复，临时写入文件不显示。主数据库无法打开时尚无快照恢复启动入口，错误页不会静默创建空档案。

快照不包含录音，当前应用也不保存录音。提醒偏好独立保存，不随学习快照回滚；恢复后按当前任务刷新学习提醒。快照只存在本机，不能替代外部备份，卸载或换机前必须导出。当前仅支持北京时间计划的积压整理。
