# 背诵计划设计系统

用户选定方向：纯白简洁、系统 iOS 风格。产品暂名“背诵计划”，首页标题“今日”。以 Flutter 重建中文导航，不沿用上游经文专用入口。

## 视觉规则

- 全白主背景，浅灰分组背景，黑色正文，蓝色操作。绿、橙、红用于通过、待复核、错误，必须附文字。
- 系统无衬线字体；正文 17px，背诵阅读正文 20px、1.8 行高。界面文案全部简体中文，日期本地化。
- 内容页 24px 左右边距。使用列表分隔和留白；用于操作汇总的少量面板圆角 16px。避免把每一句正文包进卡片。
- 参考手机为 390×844 CSS px，44px 顶部状态区、底部安全区。参考尺寸不意味着锁死真实设备高度。
- 图标统一线性，按钮目标 ≥44pt。主按钮高 52px；保存、开始考核、结束并校对各有明确状态。
- 正文支持字号调整及纵向滚动，重要文字不截断。放大字号后内容可以变长，底部操作不能覆盖正文。

## 状态和文案

“考核通过”“仍需练习”“识别待确认”“人工确认”是不同结果。临时转录标注“识别中，结果会更新”；停止后显示“正在生成最终结果”。

练习查看原文、首字提示、播放原文，都将这次会话标记为有辅助。辅助会话可记练习，不生成自动考核通过。考核模式只显示标题和当前进度，默认隐藏转录，防止原文或转录成为提示。

错误提示描述可执行动作：“未检测到声音，请检查麦克风后重试”“仍有 1 处识别疑点，请回听确认”。不把网络或识别失败写成“背诵失败”。

## 组件及布局

全局、组件、页面度量分层。HTML 原型引用 tokens.css，App 实现映射到 Cupertino 主题与共享 Design 常量；蓝色使用偏深的系统操作蓝以确保白色按钮文字对比度。

底部导航：今日 / 文库 / 计划 / 我的。导入、编辑、考核、校对采用向内导航，不同时展示底部导航。录音中退出需明确结束或继续，退出产生中断记录而非通过。

## 原型范围

设计原型提供中文页面、切换、分段、排期预览、阈值编辑和两种评分演示，不使用真实麦克风，不上传文件，不生成真实成绩。演示说明只放在原型外壳，不混入产品正常流程。
