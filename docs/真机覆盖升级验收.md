# iPhone 覆盖升级验收

状态：待真实 iPhone 执行。Windows 上的持久化与模拟容器路径迁移测试通过，不能视作真机通过。

## 准备与覆盖安装

1. 在旧版本0.2.2或实际使用版本中记录文章/段落数、计划及原截止日期、已完成任务和成绩、延期任务前后日期、报告掌握数。导出一份档案，保存到“文件”并确认可找到。
2. 新IPA需使用此前同一签名身份及应用标识 cn.recitation.recitationApp 签名。保留旧应用，直接覆盖安装0.2.3+5；不要先卸载。未签名IPA不能直接安装。
3. 打开新版，核对上述内容和日期均保留。旧版延期仍显示，但缺失来源日期的旧记录不能撤销。关闭并重开，再核对档案。
4. 延期一项到自选日期，检查原有+移入工作量正确，其他任务与已完成成绩不变。撤销后回原日期；反复点击不会重复撤销。再次延期后，旧记录不再允许撤销。
5. 完成今日任务后提前通过明天的新背，检查完成提示与下次复习；到原定日期不需重做。辅助练习与待复核不能产生完成。

## 通知与导出

1. 首次进入提醒设置不弹权限。开启学习提醒时允许通知，选择未来几分钟的北京时间；切到后台或锁屏，检查通知标题和点击打开。前台通知展示由系统处理，不以横幅出现作为唯一验收方式。
2. 同一天任务全部完成且没有到期剩余任务后，原当日学习提醒不应触发；延期、撤销、暂停后检查通知反映活跃待完成任务。提醒文案不虚报固定任务数。
3. 拒绝权限后开关不自动开启，说明可到系统设置开启。系统允许后回应用刷新，重试开启；在系统撤回权限后回应用，显示未允许。
4. 每周备份默认关闭。开启后系统安排七日提醒；取消分享不产生导出时间，成功分享并实际保存后显示上次导出日期。通知只提醒保存，不宣称自动云备份。
5. 新版导出JSON后，在独立测试档案恢复，核对延期/撤销历史、成绩和报告。不要用恢复操作覆盖唯一未备份的真实学习档案。

记录设备型号、iOS版本、安装签名方式、旧/新版本、每步结果和异常。真实设备数据丢失或通知异常时先保留档案和错误信息，勿卸载重置。

## 0.2.4 新增验收

1. 从旧版保留实际 Bundle ID 与签名身份覆盖安装，不卸载；检查文章、考核、任务、原延期记录和提醒偏好。
2. 在今日页进入计划月历，切月/回到今天，开启大字体和 VoiceOver；在计划详情重新安排新背，改配额/学习日，先取消再保存，确认旧成绩和复习日期保留。
3. 准备多天积压复习，从今日页整理，检查目标日已有复习计入配额、同段不在一天重复安排，保存后不增加完成成绩。
4. 在“我的→备份与恢复→本机快照”保存当前快照，新增文章/延期后恢复旧快照，确认弹窗说明变化范围；再恢复“恢复前档案”找回新增变化。强制关闭重开，检查恢复数据和快照仍在。
5. 检查保存失败提示与学习记录保留。卸载/换机前仍导出外部档案，本机快照随应用数据被删除；启动主数据库损坏恢复与极端低存储需单独测试。
6. 快照仅保存结构化学习档案，提醒偏好独立保存；恢复后根据任务刷新提醒。

## 0.2.5 校对与成长

1. 默写包含错字、整段漏字与重复多写，提交后检查红色高亮、蓝色删除线及原文字词/具体位置；再次考核隐藏全部原文。
2. 语音分别测试普通话、噪声、停顿、同音字、异调、近音、多音字和漏整句。结果以校正内容为主，展开原始转录应与实际系统最终结果一致；关闭同音容错后严格评分。不凭文字识别结果断言用户发音不标准。
3. “我的→学习花园”检查累计/连续学习、每周1至7天目标、徽章及小芽阶段。延期不能浇水；辅助练习不增加自动掌握徽章；恢复旧快照后花园应按恢复档案重算。
4. 320pt、大字体、VoiceOver、复制高亮内容、中文行内标点、原始转录展开和开源许可页。此版本未接入新的付费语音服务，真实识别准确率仍需录音样本校准。
