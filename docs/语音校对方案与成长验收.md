# 语音校对、默写差异与学习花园（0.2.5+7）

## 成熟方案调研

2026-10-09读取公开官方文档，以下是产品取舍依据，不代表已接入对应收费服务。

- [Remember Me官方](https://www.remem.me/)公开介绍间隔复习、拼字、填空、输入练习、连续学习和目标。借鉴练习与考核区分、连续学习目标；不采用原产品宗教内容库，也未复制上游源码。
- [微软语音评测](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/how-to-pronunciation-assessment)区分内容完整性、错读、漏读和多读；文档强调专业发音评测使用不同于普通转写的模型，长音频需要对识别结果与参考文本自行比较。借鉴逐字对齐和错漏多分类，当前一致率仍是内容评分，不称为发音分。
- [讯飞流式语音听写](https://www.xfyun.cn/doc/asr/voicedictation/API.html)说明中间结果动态修正、最终结果、标点和多候选；中文古文、噪声、较长静音可能导致识别误差。继续只用最终文本，未申请收费服务或上传密钥。
- [Apple实时语音示例](https://developer.apple.com/documentation/speech/recognizing-speech-in-live-audio)说明音频采集、最终转录和语言定制。新API有更高系统要求，当前保留iOS15兼容桥接；没有把完整背诵答案作为强制识别文本，以免掩盖漏背。

## 逐字对比

文字考核和语音考核提交后共享逐字对比组件。原文和实际输入完整保留标点；窄屏上下排列，600pt以上并排。红底下划线标出错字和原文漏字，回答用“［漏：内容］”指出缺口；多字使用蓝底删除线。每一类附原文字、实际字与字符位置，不只用颜色。差异来自评分的同一次动态规划对齐，漏一个字不会让后文全部错位。连续同类差异合并为词段说明。

空白始终忽略；标点是否评分遵循该次考核的规则快照。位置是参与评分的Unicode字符位置，渲染偏移使用UTF-16，不拆坏扩展汉字。重考清除旧结果并隐藏原文。对齐存在重复字或多种等价编辑路径时，采用稳定路径，不能将路径定位解释为确定的声学证据。

## 语音同音字容错

仅语音入口启用，可在录音前关闭，默写始终严格比较。采用开源lpinyin 2.0.3读音表，只接受单一读音、同拼音且同声调的汉字配对，例如“清→青”“兰→蓝”。多音字、异调、近音、未知字符仍按差异处理。用户说的内容没有出现时不能补齐，多说也不能删除后算对。尚未实现口音近音或音素声学评测，不能证明用户实际发音正确。

结果默认显示同音校正后的内容，绿色下划线和条目说明哪些字计为同音匹配；原始最终转录默认收起但永久保存在考核记录，可展开查看。存储新增input/acceptHomophones字段，旧记录缺省为严格文本，恢复不重新改判历史成绩。临时转录、人工辅助、技术失败和待复核仍不能自动完成任务。已有关键项用经过验证的同音配对校正文字核对，不补全文。

仍使用iOS系统中文识别；此次改善校对规则和结果显示，没有更换识别引擎。古文多音字、长静音、方言和麦克风环境需要真机样本验证。未来可基于真实音频/识别候选增加可信度与音素验证，或按用户明确配置接入商业服务。

## 学习花园

入口“我的→学习花园”。小芽从种子、破土、新叶、花苞到小花、繁花，累计学习日达到1/3/7/14/30天成长。小芽为自绘产品图形，使用现有蓝绿语义色；不引入账户、排行榜或装饰背景。

有有效时长的练习/考核及保存的自动通过计学习日，同一天只算一次。辅助练习可浇水；人工确认、临时处理中、技术失败、改期与打开页面不浇水。当天还没学习时连续天数从昨天续算，跨一个完整未学习日则重新开始；累计成长和已取得最长连续记录不会因休息倒退。

每周按北京时间周一开始，默认目标3天，可选1至7天；偏好独立持久化。初次掌握、三日相伴、一周坚持、温故知新、积少成多徽章从真实不可变学习事件计算，掌握与复习只认可无辅助自动通过。重考同一新背段落不重复增加掌握数，恢复快照后随档案重新计算，避免缓存虚构奖励。
